# PhonePe — UPI Payment Success Screen

**DayZer0 Frontend Project · Easy**

Build PhonePe's UPI payment success screen using only HTML and CSS.

## What to build

A single `index.html` that renders a mobile-first payment success screen:

- Animated green checkmark (CSS only — no JS libraries)
- Payment amount: ₹1,500
- Recipient: Rahul Mehta (`rahul.mehta@oksbi`)
- Transaction ID: `TXN2025060412345678`
- Done button in PhonePe purple (`#5f259f`)

## Rules

- Mobile-first layout (base: 375px, also works on desktop)
- Semantic HTML only — `<main>`, `<section>`, `<p>`, `<button>`
- No frameworks, no libraries, no JavaScript

## How to submit

1. Create a branch: `git checkout -b feature/payment-success`
2. Build your screen in `index.html`
3. Push and open a Pull Request against `main`
4. Raj will review your code — once approved it merges automatically
